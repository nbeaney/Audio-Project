# Audio-Project

In this project, I'm setting out to explore a number of concepts I've learnt about in my physics degree more deeply, namely the Heisenberg Uncertainty Principle, Fourier Transforms and Convolution. Outside of my degree, I enjoy recording and mixing my own music in Logic Pro, and so this project is intended to develop my understanding of the fundamental mathematics behind how tools such as EQs and reverbs, plugins I use every day, actually work.
